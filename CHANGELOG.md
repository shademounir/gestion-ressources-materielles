# Changelog

All notable changes to this project will be documented in this file.

## v1.0.0 - Stable Backend + DevSecOps Foundation

### Added

- JWT authentication and stateless logout foundations.
- RBAC access protection.
- User administration basics: create user, assign role, deactivate user.
- Department creation and user-to-department assignment.
- Department needs with `Need` and `NeedItem`.
- Supplier creation, history and deactivation.
- Tender creation from need and tender publication.
- Supplier offer submission and winner selection.
- Unit tests for backend modules and frontend foundation.
- SonarCloud, CodeQL and Semgrep DevSecOps integrations.
- GitHub Actions artifacts for coverage, builds and Semgrep reports.
- Release notes and release process documentation.

### Not Included

- Full business frontend.
- Production deployment.
- GitHub Release creation.
- Git tag creation.
- JFrog Artifactory integration.
- Complete inventory, assignment and maintenance workflows.
